# Battly Mobile 2.2.9

Version code: 10000030. Code 10000029 was uploaded provisionally but removed from the release draft before review; it is not the deliverable. Release/Gplay minification and resource shrinking remain disabled.

## Changes

- Canonical, separator-aware confinement for shared documents, modpack manifest downloads and ZIP overrides.
- SAF create/read/rename/delete operations remain supported; link management preserves the link rather than deleting its target.
- External native plugins default to disabled and require an explicit warning/approval bound to the package and APK signing identity. Existing implicit approvals are not migrated.
- Bundled native dependencies remain automatic. Approved plugin JVM properties and native paths retain the existing metadata contract.
- Discord callbacks require a pending, matching, unexpired nonce. Loopback and deep links compete for one accepted transaction; accepted tokens remain recoverable during activity recreation until completion.
- Analytics initialize automatically in the launcher; offline behavior and Android/device permissions are unchanged.
- Native release panel, Spanish announcement and ten localized news feeds with English fallback updated.

## Verification

- 314 JVM unit tests, zero failures; the Windows symbolic-link test is skipped because File.getCanonicalPath has different link semantics there.
- Eight Android instrumentation tests passed on Hytale API35, covering actual Android symlink checks and document provider operations, native plugins, OAuth, Modrinth and CurseForge installation, and the native release panel.
- A locally built, harmless x86_64 plugin APK was discovered disabled, approved against its signer, included in native/JVM paths, loaded with System.load, then disabled again.
- A valid local Modrinth archive installed a downloaded configuration file plus regular and client overrides. A malicious manifest path was rejected before download. Tests do not use production accounts or send dummy playtime.
- 1100 audited strings across 47 translated qualifiers; 51 strings.xml files contain the versioned panel. Ten news locales plus identical English fallback validate.
- Signed production APK/AAB built with ARM ABIs and native debug symbols. Artifact checks reject Codex attachments and release secrets.
